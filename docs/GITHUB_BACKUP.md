# GitHub publication scope

Destination requested by the project owner: `Seunghpark/GradProject` (public).
This publication contains the current 0.6.0 backend/frontend sources, built
frontend, publishable model/aggregate JSON artifacts, tests, documentation,
selected application screenshots and the checked graduation report/slides.
The complete dated review ZIP is also included for a single-file download.

The report and slides are academic review copies. Their publication does not
mean student/adviser approval or school submission. Earlier screenshots and
dated records are historical evidence, not all current interface screenshots.
The original 104-game experiment and additional 35-game audit remain distinct.
Neural-model superiority, low-elo performance and coaching efficacy are unproven.

## Excluded private or generated files

API keys and local `.env` files, private notes/rank/collection SQLite stores,
raw JSONL player records, client certificates, request caches, temporary probes,
private backups, installed dependencies and Git credential/configuration files
are excluded. Sanitized `.env.example`, numerical model parameters and aggregate
research reports are included. No original lost-computer experiment is claimed
to have been recovered.

The current 185-game raw collection is in the separate private local backup
`.private-backups/20261030T095835552204Z` (14 files verified). This public GitHub
repository alone does not back up those private databases. Copy that backup to
an owner-controlled private off-computer destination separately.

Use `PUBLICATION_MANIFEST.json` at the repository root to verify this publication's
file sizes, SHA-256 values and expected Git blob IDs. The manifest excludes its
own hash. Later edits require a new manifest. The existing local checkout has an
unborn branch; synchronizing its Git metadata after connector publication is a
separate step and must preserve local uncommitted and ignored private data.
