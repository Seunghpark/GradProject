# 국문 관련연구: 검증된 후보 3편

확인일: 2026-10-28. 아래는 논문 원문 또는 한국연구재단 KCI의 공식 서지·초록을 확인한 국문 연구다. 제목만 보고 방법이나 결과를 추정하지 않았다. LolAi.gg의 자체 결과와 선행연구 수치를 혼합하지 않으며, 다른 표본·시점·검증 조건의 정확도를 직접 우열 비교하지 않는다. 각 요약은 짧게 유지했으므로 보고서에서는 필요한 부분을 인용번호와 함께 옮기고, 중복 전재로 분량을 늘리지 않는다.

## K1. 챔피언 조합을 이용한 딥러닝 경기 시작 예측

서지: 김철기, 이수원. (2020). 양방향 순환신경망 임베딩을 이용한 리그오브레전드 승패 예측. 정보처리학회논문지 소프트웨어 및 데이터 공학(KIPS Transactions on Software and Data Engineering), 9(2), 61-68. DOI: [10.3745/KTSDE.2020.9.2.61](https://doi.org/10.3745/KTSDE.2020.9.2.61).

확인 출처: [학회 공식 논문 페이지](https://ktsde.kips.or.kr/digital-library/23258), [KCI 공식 국문 서지·초록](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002558753), [학회 원문 PDF 주소](https://ktsde.kips.or.kr/digital-library/manuscript/file/23258/04-19M-05-046R-%EA%B9%80%EC%B2%A0%EA%B8%B0_061-068.pdf). 저자 국문명·권호·DOI는 공식 KCI와 일치한다. PDF 검색 색인에서 국문 제목·본문을 확인했으나, PDF 직접 열기는 도구에서 실패했다. 요약은 학회·KCI 초록에 근거하며 원문 상세 구현을 확인한 것으로 표현하지 않는다.

보고서용 요약: 이 연구는 경기 시작 단계의 팀별 챔피언 능력치 조합을 양방향 LSTM 임베딩으로 표현하여 승패를 예측하는 딥러닝 모형을 제안하였다. 리그 오브 레전드 승패 예측에 학습된 신경망 표현을 적용한 국내 사례라는 점에서 관련된다. LolAi.gg는 챔피언 조합이나 순환신경망을 구현한 연구가 아니라, 실제 초기 경기 통계의 팀 차이를 세 은닉층 MLP에 입력한다. 입력 정보가 이용 가능한 시점과 구조가 다르므로 해당 논문의 재현이나 직접 성능 비교로 서술하지 않는다. 본 프로젝트의 신경망 성능이 우수하다는 근거로도 사용하지 않는다.

## K2. 초반 10분 정보와 변수중요도

서지: 김용우, 김영민. (2021). 기계학습을 활용한 게임승패 예측 및 변수중요도 산출을 통한 전략방향 도출. 한국게임학회 논문지, 21(4), 3-12. DOI: [10.7583/JKGS.2021.21.4.3](https://doi.org/10.7583/JKGS.2021.21.4.3).

확인 출처: [KCI 공식 서지·초록](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002751013), [한양대학교 저장소의 원문 PDF 주소](https://scholarworks.bwise.kr/hanyang/bitstream/2021.sw.hanyang/141303/1/82134.pdf). KCI 등록번호 ART002751013. DOI·학술지·권호·쪽수는 대학 원문 첫쪽의 검색 색인에서도 일치한다. 원문 PDF 직접 열기는 저장소 리디렉션으로 실패했으므로 상세 구현·분할 조건은 확인하지 않았다.

보고서용 요약: 이 연구는 경기 초반 10분의 자료로 랭크별 최종 승패 모형을 구성하고 변수중요도를 분석하였다. 초반 정보의 예측 가능성과 랭크에 따른 차이를 검토한다는 점에서 LolAi.gg의 시점 제한과 관련된다. 다만 LolAi.gg의 실제 프레임은 약 9분에 해당하며, 작은 편의표본에 세 은닉층 신경망을 적용한 탐색적 실험이다. 따라서 동일한 문제 설정이나 재현 실험으로 표현하지 않는다. 변수중요도에 대한 논의도 특정 행동의 인과효과 또는 플레이어 승률 향상 증거로 옮기지 않는다.

## K3. 일반 사용자 자료와 개인·팀 단위 모형

서지: 김예지, 민정혜. (2023). AOS 게임 유저 데이터를 이용한 승패 예측. 한국컴퓨터정보학회논문지, 28(12), 23-32. DOI: [10.9708/jksci.2023.28.12.023](https://doi.org/10.9708/jksci.2023.28.12.023).

확인 출처: [KCI 공식 국문 서지·초록](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART003028378), [학술지 원문 PDF](https://journal.kci.go.kr/jksci/archive/articlePdf?artiId=ART003028378). KCI 등록번호 ART003028378. PDF의 국문 요약, 서론·관련연구, 데이터 수집과 모형 설명 부분을 확인했다. 본문은 국문이며 영문 제목과 초록을 병기한다. PDF 첫쪽의 저자 로마자 표기와 KCI 국문 저자명을 대조하였다.

보고서용 요약: 이 연구는 일반 사용자의 Riot API 자료를 수집하고 개인 단위와 팀 단위 모형을 구분하여 여러 기계학습 알고리즘을 비교하였다. 데이터 수집·전처리와 분석 단위를 구분하는 설계가 LolAi.gg의 팀 차이 특성 구성에 참고가 된다. 논문은 전체 게임 관점을 채택한다고 설명하므로, 초기 프레임만 사용하는 본 프로젝트와 예측 문제가 같다고 단정할 수 없다. LolAi.gg는 적은 실제 자료에서 신경망과 로지스틱·상수 기준선을 동일 분할로 비교하고, 신경망의 약한 결과와 과적합 가능성을 명시한다.

## 인용 시 주의

- 위 3편은 국문 연구 후보이며, 영문 연구 최소 3편은 별도로 확보해야 한다.
- K1과 K2는 학회 또는 KCI 공식 초록에 근거한 요약이다. 초록에 없는 자료 분할, 입력 시점, 세부 하이퍼파라미터나 누수 여부를 임의로 적지 않는다.
- K3의 전체 게임 관점과 본 프로젝트의 엄격한 초기 시점 제한을 구분한다.
- 선행연구의 자료 수·정확도를 본 프로젝트의 실적으로 바꾸지 않는다. 본 프로젝트의 수치와 한계는 DEEP_LEARNING_RESULTS.md를 따른다.
- 최종 참고문헌 번호와 서식은 실제 지정 보고서 양식에 맞춰 정리한다. DOI 미확인 항목을 추정해 채우지 않는다.

선택 가능한 추가 국문 참고문헌: 김동욱, 박제원, 최재현. (2017). 기계학습을 활용한 E-Sports 승·패 예측에 관한 연구. 한국IT정책경영학회 논문지, 9(1), 319-325. [KCI](https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002199389). 초록 확인만 완료했으며 DOI는 확인되지 않았다. 필수 세 편에는 위 K1-K3을 우선 사용한다.
