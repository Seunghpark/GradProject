# LolAi.gg 프로젝트 이력과 향후 아이디어

기록일: 2026년 10월 29일. 이 문서는 사용자가 설명한 과거 개발 경험, 새로 제공한 정리 자료, 현재 프로젝트에서 확인한 결과와 향후 아이디어를 구분해 보관한다. 보고서와 발표자료의 실험 결과를 변경하는 근거로 사용하지 않는다.

## 사용자가 설명한 과거 이력과 문제의식

사용자는 현재 작업 이전에도 LolAi.gg의 프로토타입을 개발했으며, 당시 사용하던 컴퓨터를 잃어버렸다고 설명했다. 과거 프로토타입의 존재와 개발 경험은 사용자 진술로 기록한다. 해당 컴퓨터의 원본 코드, 학습 데이터, 모델 파일과 실험 로그는 현재 작업에서 복구하거나 대조하지 못했다. 현재 체크아웃에서 확인한 구현과 과거 프로토타입의 구현 범위는 따로 관리한다.

사용자는 기존 서비스의 조언을 따른 뒤 연패를 겪은 경험도 설명했다. 이 경험은 상황에 맞는 피드백과 설명이 필요하다는 제품 문제의식으로 남긴다. 조언 이후 연패가 있었다는 관찰적 경험이며, 그 조언이 연패를 일으켰다는 인과 검증이나 특정 서비스의 효과 측정 결과로 사용하지 않는다. 현재 승패 예측 실험 역시 조언이 사용자 승률을 높이거나 낮추는지를 평가한 실험이 아니다.

## 업로드한 과거 정리 자료의 내용과 출처

자료: [LolAi.gg Project Notes.pdf](<C:/Users/sh Park/Downloads/LolAi.gg Project Notes.pdf>), 총 3쪽. 사용자는 Claude로 과거 내용을 정리한 자료라고 설명했다. PDF 3쪽에도 과거 대화를 보관한 자료가 출처라고 적혀 있다. 아래 쪽수는 PDF의 실제 순서 및 인쇄된 `Page 1 of 3`부터 `Page 3 of 3`까지의 표기와 일치한다.

- **과거 제안서 정보 — PDF 1쪽:** 2024학년도 2학기 제안서, 작성일 2024년 9월 20일, 지도교수 한환수, 당시 명칭 LOL Assistant로 정리되어 있다. 9개월, 예산 0원의 계획과 Riot API 수집·전처리, 지도학습, 아이템·전략 추천, 대시보드 및 실시간 활용 구상을 설명한다. 이는 PDF가 요약한 제안 당시의 계획이며, 모든 기능이 완성됐다는 확인은 아니다.
- **개발 기간 정리 — PDF 3쪽:** 프로젝트 기간을 `2024.08 ~ 2026.10`으로 통일하라고 적혀 있다. 이 기간은 과거 자료를 정리한 문서의 표기이며, 해당 기간 전체의 연속적인 개발 기록이나 완성 기능을 별도로 입증하지는 않는다.
- **과거 실험 수치 주장 — PDF 1쪽:** 10명 × 100경기의 총 1,000경기, 약 10,000개의 플레이어·경기 기록을 사용한 XGBoost의 정확도 79%, ROC-AUC 0.86을 최종 결과로 적고 있다. PDF는 이 값을 사용하라고 안내하지만, 이번에 함께 제공된 것은 정리 PDF이며 해당 데이터셋, 학습된 모델, 평가 분할과 실행 로그를 복구한 것은 아니다. 따라서 이 수치는 **업로드된 과거 정리 문서의 주장**으로 보관하며, 현재 재현·검증한 성능으로 표기하지 않는다.
- **과거 구현 서술 및 확장 구상 — PDF 2쪽:** 예측기에서 플레이어 분석 서비스로 발전했다고 설명하며, 시간별 승률 변화, 예측 근거, FastAPI와 React 연결, 플레이어 수준 특성과 행동·소통 특성을 언급한다. 이 서술만으로 현재 체크아웃에 그 기능이 모두 구현됐다고 판단하지 않는다. 저티어 특성의 효과는 PDF 자체도 검증 중으로 표현하라고 안내한다.
- **자료 내부의 한계 — PDF 3쪽:** 과거 임시 수치를 사용하지 말라는 안내와 함께, 다이아몬드 이상 자료라는 서술과 10명 기준 수집 범위 사이의 설명이 필요하다고 적고 있다. 1,000경기의 중복 여부, 참가자 구성, 정보 시점 및 평가 절차는 원자료가 확보될 때 확인할 항목으로 남긴다.

과거 XGBoost 수치와 현재 MLP 수치는 데이터 및 평가 절차의 동일성이 확인되지 않았다. 두 결과를 같은 실험의 개선 전후로 비교하거나, 과거 수치로 현재 결과를 대체하지 않는다.

## 현재 프로젝트에서 확인한 구현과 실험

현재 근거는 [딥러닝 실험 기록](DEEP_LEARNING_RESULTS.md), [로지스틱 회귀 실험 기록](REAL_MODEL_RESULTS.md), [모델 카드](MODEL_CARD.md)와 현재 구현이다.

현재 구현은 React·TypeScript 화면, FastAPI 서버, Riot 경기·타임라인 조회와 SQLite 캐시, 완료 경기의 통계·팀 골드 흐름, 규칙 기반 복기 문구, 분석 JSON 내보내기 및 학습된 모델의 추론을 포함한다. 개인 플레이어의 조회 화면이 있다는 사실과 개인별 전략을 학습·검증한 추천 기능은 구분한다.

실제 KR 랭크 솔로/듀오 고유 경기 104개를 시간순으로 앞선 83개 학습 경기와 이후 21개 평가 경기로 나눴다. 자료의 경기 시작 시각은 2026년 10월 20일부터 28일까지이며 패치는 16.20과 16.21이다. 현재 신경망은 `6 → 16 → 8 → 4 → 1` 구조의 MLP이며, 학습 가능한 가중치와 편향은 289개이다.

- MLP 평가: 10/21개 정답, 정확도 **47.62%**, ROC-AUC **0.49091**, Brier 점수 **0.372683**.
- 동일 분할의 로지스틱 회귀: 12/21개 정답, 정확도 **57.14%**, ROC-AUC **0.60909**, Brier 점수 **0.263561**.
- 학습 승리 비율을 사용하는 상수 기준선: 정확도 **47.62%**, ROC-AUC **0.50000**, Brier 점수 **0.259862**.

신경망의 학습 정확도 95.18%는 학습 자료에서 계산한 진단값이다. 평가 정확도와 구분하며, 두 값의 큰 차이는 과적합 가능성과 일치한다. 21경기 평가셋은 앞선 로지스틱 회귀 실험에서 이미 확인한 자료를 재사용한 탐색적 비교이고, 새로운 독립 최종 검증이 아니다. 작은 연결 표본과 플레이어 중복에 따른 한계가 있다. 현재 실험은 신경망의 예측 우수성, 확률 보정, 사용자 승률 향상이나 인과적 코칭 효과를 입증하지 않았다.

## 향후 아이디어와 현재 구현 범위

현재 선택한 챔피언·역할에 대한 OP.GG·FOW·GGQ·DEEPLOL·YOUR.GG 공식 링크와 패치별 YouTube 검색 허브를 추가했다. Data Dragon 버전 조회 및 패치 입력 검증도 작동한다. 각 서비스의 내부 기능 통합이나 영상 추천 품질 검증은 아니다. 구현·검증과 공식 연동 후보의 상세 근거는 [외부 자료 통합 기록](EXTERNAL_INTEGRATIONS.md)에 있다.

다음 항목은 사용자 문제의식과 PDF 1–2쪽의 방향을 바탕으로 정리한 추가 구상이다. 현재 버전에 모두 구현된 기능이나 확인된 성과로 소개하지 않는다.

- **개인화된 복기와 피드백:** 포지션, 주력·비주력 역할, 챔피언 경험, 최근 경기와 반복되는 실수 등을 구분해 사용자에게 맞는 검토 항목을 제안한다. 먼저 각 특성의 정의와 관찰 기간을 정하고, 충분한 개인 이력 및 별도의 평가 자료로 유용성을 확인해야 한다. 현재는 경기 통계에 대한 규칙 기반 복기 문구를 제공한다.
- **패치별 자료와 설명 근거:** 챔피언·아이템·게임 규칙 자료를 패치 버전과 연결해 피드백의 근거와 적용 시점을 설명하는 방향이다. 자료 확보 경로와 버전을 확인하고 패치 변화에 따른 성능을 따로 평가해야 한다. 현재 두 패치의 수집 표본이 있다는 사실만으로 패치별 추천·적응 기능이 구현됐다고 표현하지 않는다.
- **플레이 특성과 행동·소통 프로필:** PDF 2쪽은 라인전·한타·파밍·공격 및 수비 성향과 협업·소통·동료 피드백을 구분하는 아이디어를 제시한다. 이러한 행동 라벨에는 관찰 가능한 데이터, 명확한 기준, 필요한 이용자 동의와 오류 정정 방법이 먼저 필요하다. 단일 경기 통계나 승패로 의도·인성·협업 능력을 단정하지 않는다. 채팅·동료 평가 수집과 행동 프로필 학습은 현재 검증된 구현 범위에 포함하지 않는다.
- **새로운 실험과 서비스 효과 확인:** 과거 자료가 복구되면 데이터 중복, 정보 시점, 분할, 모델과 실행 로그부터 대조한다. 향후 예측 비교에는 새 평가 자료를 확보하고, 피드백의 유용성이나 승률 변화는 예측 정확도와 별도의 연구 질문으로 평가한다. 아직 측정하지 않은 효과에 수치를 붙이지 않는다.

## 보고서와 발표자료에 적용할 기록 기준

과거 경험은 사용자 진술, PDF의 구현·성능 서술은 출처 쪽수가 있는 과거 자료의 주장, 현재 결과는 저장된 실험과 검증 기록, 추가 기능은 향후 계획으로 표시한다. 앞서 제공된 보고서·발표 예시는 사용자가 실제 작업 결과와 구분하도록 확인한 자료이므로 구현 또는 성능의 증거로 채택하지 않는다. 현재 보고서와 발표자료의 104경기 MLP·로지스틱 회귀 비교 및 그 한계는 유지한다.

## 사용자가 붙여 넣은 과거 정리의 추가 세부 내용

아래 항목은 사용자가 제공한 대화 정리와 기억을 빠짐없이 보관하기 위한 기록이다. 원본 실험·이력 검증 또는 현재 구현 완료를 뜻하지 않는다. 현재 기능별 완료 여부는 [전체 기능 대조](FEATURE_COVERAGE_AUDIT.md)에 따로 표시한다.

- **과거 모델별 수치:** 로지스틱 회귀 정확도 71%·ROC-AUC 0.77, Random Forest 76%·0.83, XGBoost 79%·0.86. 자료 규모는 10명×100경기=1,000경기 및 약10,000개의 플레이어·경기 행으로 설명됐다. 이 세 모델의 원본 실행과 현재104경기 비교는 동일 실험으로 취급하지 않는다.
- **기억한 입력 특성 아홉 개:** gold_diff_10, xp_diff_10, cs_diff_10, vision_score, control_wards_placed, objective_participation, worthless_deaths, role_winrate, champ_winrate. 현재 모델 입력은 별도로 정의된 여섯 개이다.
- **수치가 확인되지 않은 항목:** 전체 과거 특성 수, API 호출 수, AFK·트롤 비율, 저티어와 고티어의 정확도 차이는 기록되지 않았다고 정리되어 있다. 임의로 보충하지 않는다.
- **과거 기술 구성·계획:** Python, pandas, scikit-learn, XGBoost, FastAPI, React, TypeScript, SQLite/PostgreSQL. 10–15분 관측, 아이템·전략 추천, 시간별 승률과 특성 기여도, 경량 실시간 활용 및 알파/베타 테스트를 언급한다. 현재 체크아웃에 이 전체 구성이 모두 구현되어 있다는 뜻은 아니다.
- **개인화 축의 세부 구상:** 다섯 포지션별 승률, 주력/비주력 역할 차이, 챔피언 승률·숙련도, 최근 폼, 라인전·한타·파밍·공격/수비 성향, AFK·경기 완주율. 별도의 행동 축에는 매너·소통 빈도·협력·긍정/부정 소통·동료 평가를 포함한다. 효과는 검증 중으로 표현하고 새 수치를 만들지 않는다.
- **과거 임시 수치 경고:** “5,000~10,000건”, “70~75%/70% 초중반”, 특정 첫 타워·드래곤·골드 조건에서 “80% 이상”, “한국/북미 서버”라는 옛 문구를 현재 검증 결과로 사용하지 말라는 안내가 있다. 현재 보고서는 실제104경기의 출처·서버·평가만 기록한다.
- **기간·표본 범위 충돌:** 이력서의2024.08~2026.05, 연구 프로젝트의2025.07~2025.09, 제안서의2024-09 작성 및9개월 계획이 함께 언급됐다. PDF에는2024.08~2026.10으로 통일하라는 정리도 있지만, 이력 원본을 검증해 기간을 확정한 것은 아니다. 다이아 이상 자료라는 서술과10명 구성 역시 원자료 확인이 필요하다.
- **과거 참고 목록:** Riot Developer Portal, NVIDIA G-Assist, Overwolf, Riot AI 대전 FAQ, 브런치 듀랑고 개발자의 LoL AI 글, OP.GG, FOW, Blitz, oracle-devrel/leagueoflegends-optimizer. 참고 목록에 있다는 사실과 코드·API를 연동했다는 사실은 구분한다.
- **지원서 활용 맥락:** 넥슨네트웍스 게임서비스의 게이머·분석가 이야기, 기아 Data Scientist의 예측 모델 사례, CJ 문항의 설명력 이야기 및 중복 제거, NH의 상세 프로젝트 설명에 사용됐다고 정리되어 있다. 과거 지원서 자체를 이번 작업에서 검증하거나 수정하지 않았다.
- **개인 게임 경험의 맥락:** 메이플2006년부터, LoL시즌4 SEA→EUW골드→KR2018년부터 골드/플래티넘, 탑 케넨 주력,2023-11-19고척 롤드컵 결승 관람으로 적혀 있다. 사용자 제공 이력이며 모델 데이터·성능의 증거로 사용하지 않는다.

이 기록은 사용자가 붙여 넣은 정리와 제공한PDF를 보관한 것이며, 모든 과거 ChatGPT·Claude 대화나 분실 컴퓨터를 별도로 복구·검색했다고 주장하지 않는다.
